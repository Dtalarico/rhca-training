# rhca-training
My RHCSA (Red Hat Certified System Administrator) training repository documenting labs, commands, notes and troubleshooting while studying with Sander van Vugt

## Practical administration lab framework

The [RHCSA Practical Administration Lab Framework](docs/PRACTICAL_LAB_FRAMEWORK.md) describes a proposed path from knowing Linux commands to independently solving real system-administration tickets on a dedicated RHEL 10 VM.

Learning sequence: **PROBLEM → INSPECT → PLAN → EXECUTE → TROUBLESHOOT → VERIFY → DOCUMENT → RETEST**. It complements guided **DO → SEE → NAME → REMEMBER** practice, includes verification and delayed independent retesting, and does not claim labs have already been completed.

**Current priority:** NOS-120 exam preparation. Hands-on tickets will be developed and attempted later, with actual results documented as they occur.
